# Domaine de la Rossignole — gestion des commandes (préversion d'essai)

Maquette fonctionnelle à tester en ligne : présentation + trois vues (ordinateur du bureau, tablette du poste d'étiquetage, TV de l'atelier).

- Tout tient dans `index.html` (aucune installation).
- Les données sont **fictives**.
- Les appareils qui ouvrent le lien se synchronisent en direct via un canal public ntfy.sh. Ne pas saisir de vraies données clients.
- Lien direct vers une vue : `#pres`, `#pc`, `#tab`, `#tv`. Salle privée : `?salle=xxxx`.
